# before starting coding

- Always create a TODO.md to set up what to do and keep it updated.
- Always use a STRUCTURE.md to summarize how the code is divided and which part does what.
- .log files are your friends, use them from one session to another.
- Keep the .md files updated.
- **Per-task plan files**: during research time, create a plan file for each TODO item
  you are going to implement, in the `plans/` subdirectory. The file describes the process
  to follow (research findings, steps, decisions, open questions). Keep it updated:
  - when requirements change → update it,
  - as work progresses → mark steps done / partially done,
  - on completion → note what shipped and what was skipped/deferred.
  One file per feature/change, named `plans/<slug>.md`. Keep the subdirectory clean.
