# before starting coding

- Always create a TODO.md to set up what to do and keep it updated.
- Always use a STRUCTURE.md to summarize how the code is divided and which part does what.
- .log files are your friends, use them from one session to another.
- Keep the .md files updated.

# behave
- This file is not project specific.
- KISS — don't overengineer.
- You can do everything if you use discipline and think smart.
- Always ask yourself, "Am I building something that already exists?" If yes, exploit it.
- Ask me questions — better to ask than make false assumptions.
